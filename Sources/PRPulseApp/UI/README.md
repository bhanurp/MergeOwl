# PR Pulse — User Guide

The user guide is maintained in the [main README](../../../README.md).

Start there for installation, first-launch security guidance, connecting GitHub, PR triage, Settings, and troubleshooting. The app lives in the macOS menu bar: click its flower icon, then the gear button to open Settings.

Keeping one user guide avoids conflicting UI labels and token-storage instructions. Do not delete Keychain entries or reset app data as a routine troubleshooting step.
