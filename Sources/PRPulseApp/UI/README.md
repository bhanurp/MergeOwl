# MergeOwl — User Guide

The user guide is maintained in the [main README](../../../README.md).

Start there for installation, first-launch security guidance, connecting GitHub, PR triage, Settings, and troubleshooting. The app lives in the macOS menu bar: click its owl icon, then More → Settings. Older PR Pulse releases use the flower icon; v0.2.0 uses a gear button.

Keeping one user guide avoids conflicting UI labels and token-storage instructions. Do not delete Keychain entries or reset app data as a routine troubleshooting step.
